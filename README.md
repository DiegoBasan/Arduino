# Arduino

Proyectos de Arduino, organizados por carpeta:

- **Blink_LED** — parpadeo básico de un LED.
- **Brazo_Bluetooth_Control** — brazo robótico de 7 servos controlado por Bluetooth (grabar/reproducir posiciones).
- **Brazo_Robot_Gestos** — brazo robótico que agarra objetos y hace gestos de sí/no.
- **Brazo_Rutina_Chiste** — rutina de movimientos del brazo (chiste).
- **Brazo_Rutina_Solo** — rutina de movimientos del brazo (solo).
- **Dado** — dado electrónico con display de 7 segmentos y botón.
- **Display_7_Segmentos** — pruebas con display de 7 segmentos.
- **LED-CORRIDO** — luces corridas controladas por Bluetooth (SoftwareSerial).
- **LED-CORRIDO-INDIVIDUAL** — luces corridas secuenciales.
- **Leds_con_boton** — control de motor/LEDs con botones y potenciómetro.
- **Practica_2** — práctica de encendido/apagado de LEDs.
- **Servo_Sweep_0_180** — barrido de servo de 0° a 180°.
- **Servo_Sweep_90_180** — barrido de servo de 90° a 180°.
- **libraries** — librerías de Arduino.
